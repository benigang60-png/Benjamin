# 🎹 پیانو استودیو

پیانوی آنلاین فارسی با ۲۶ آهنگ، حالت آموزش، پخش خودکار، ۸ ساز و بخش درام.

## چطور اجرا کنم؟

### راه ۱ — فایل تک‌نفره (ساده‌ترین)
فایل `piano-studio-offline.html` را دانلود کن و روی آن دوبار کلیک کن.
کل سایت (هر ۴ صفحه) داخل همین یک فایل است و **بدون اینترنت** کار می‌کند.
می‌توانی این فایل را در واتساپ/تلگرام برای دوستانت بفرستی.

### راه ۲ — سرور محلی
```bash
cd piano
python3 -m http.server 8080
```
سپس در مرورگر: http://localhost:8080

### راه ۳ — GitHub Pages
در GitHub: Settings ← Pages ← Source: Deploy from a branch
برنچ `arena/01a061c1-benjamin` و پوشه `/ (root)` را انتخاب کن.
آدرس نهایی: `https://benigang60-png.github.io/Benjamin/piano/`

## ساختار
| فایل | توضیح |
|---|---|
| `index.html` | صفحه اصلی |
| `songs.html` | کتابخانه ۲۶ آهنگ با جست‌وجو و فیلتر |
| `learn.html` | راهنما و مسیر یادگیری |
| `progress.html` | پیشرفت و نشان‌ها |
| `play.html` | پیانو (آموزش، پخش خودکار، درام، آزاد) |
| `piano-studio-offline.html` | نسخه تک‌فایلی همه‌چیز‌سرهم |
| `build-offline.py` | ساخت مجدد نسخه تک‌فایلی |

بعد از تغییر هر صفحه، برای به‌روزرسانی فایل آفلاین: `python3 build-offline.py`
